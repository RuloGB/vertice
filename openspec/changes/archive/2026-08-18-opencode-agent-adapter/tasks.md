**Read this block before writing any code in this phase.** Tasks 2.1–2.3 are ordered on purpose and that order is the whole point of this change's TDD discipline (design §6, proposal "Approach"). A whole-object-replacement merge and a correct per-key merge both pass "an agent in each file" — they only disagree on `partial-override/`. If the merge function is written before this test exists and fails, the test becomes confirmation instead of a safeguard, and the one property this change exists to protect is gone.
